# FOURCUT CLUB — 나만의 인생네컷 웹앱

사진 4장을 올리고 필터, 프레임 컬러, 문구, 스티커를 조합해 나만의 포토부스 사진을 만드는 반응형 웹앱입니다. 별도의 빌드 도구나 서버 없이 실행할 수 있는 HTML/CSS/JavaScript 프로젝트입니다.

## 빠른 시작

1. `fourcut-studio.zip`을 압축 해제합니다.
2. `index.html`을 Chrome, Edge, Safari 등 최신 브라우저에서 엽니다.
3. 사진을 1~4장 업로드하고 원하는 필터와 프레임을 선택합니다.
4. 위·아래 문구를 편집하고 스티커를 추가합니다.
5. 미리보기에서 스티커를 드래그해 위치를 조정한 다음 **사진 다운로드**를 누릅니다.

> 폰트는 인터넷 연결이 있으면 Google Fonts를 사용하고, 연결이 없으면 시스템 폰트로 표시됩니다. 이미지 편집과 PNG 생성은 브라우저의 Canvas API에서 처리합니다.

## 기능

- **사진 업로드:** 슬롯별 업로드 또는 여러 장 동시 업로드. 최대 4장.
- **레이아웃:** 세로 4컷 / 2 × 2.
- **프레임 테마:** 라일락, 핑크, 버터, 민트, 나이트.
- **필터:** 원본, 소프트, 필름, 흑백, 비비드, 웜톤.
- **프레임 문구:** 위·아래 문구 편집 및 날짜 표시.
- **스티커:** 하트, 별, 꽃, 리본, 체리, 고양이 등. 추가 후 미리보기에서 드래그 가능.
- **내보내기:** PNG 파일 다운로드.
- **반응형 UI:** 데스크톱과 모바일 화면에 맞춰 레이아웃 변경.
- **개인정보:** 사진 파일을 외부 서버로 전송하지 않으며, 브라우저 메모리 안에서만 처리.

## 파일 구조

```text
fourcut-studio/
├── index.html   # 화면 구조 및 접근성 레이블
├── styles.css   # 반응형 레이아웃과 시각 디자인
├── app.js       # 업로드, Canvas 렌더링, 필터, 스티커, 다운로드
├── README.md    # 실행 및 유지보수 안내
└── PRD.md       # 제품 요구사항 정의서
```

## 기술 구성

- HTML5
- CSS3 (glassmorphism, mesh-gradient 계열 배경, 반응형 레이아웃)
- Vanilla JavaScript (ES6+)
- Canvas 2D API (사진 자르기, 색상 필터, 텍스트 및 스티커 렌더링, PNG 변환)
- FileReader API (로컬 이미지 읽기)

외부 JavaScript 라이브러리 및 서버 API는 사용하지 않습니다.

## 사용 팁

- 사진을 세로 4컷에서 2×2로 바꾸면 서로 다른 구성이 가능합니다.
- 사진은 슬롯 번호 순서로 배치됩니다. 특정 사진을 다시 선택하면 해당 슬롯 사진만 바뀝니다.
- 스티커는 추가된 뒤 사진 미리보기에서 직접 드래그합니다.
- 캔버스의 다운로드 해상도는 미리보기의 화면 크기와 별개로 렌더링됩니다.
- 사진을 한 장 이상 업로드해야 다운로드가 활성 동작합니다. 비어 있는 슬롯은 디자인용 플레이스홀더로 표시됩니다.

## 알려진 제한 사항

- 이미지 크롭 위치를 개별 조정하는 기능, 실행 취소/다시 실행, 개별 사진별 필터는 현재 버전에 포함되지 않습니다.
- 브라우저 및 운영체제에 따라 이모지 스티커 모양이 다를 수 있습니다.
- Google Fonts는 네트워크가 차단된 환경에서 대체 폰트로 표시됩니다.
- 앱을 닫거나 새로고침하면 업로드한 사진과 설정은 초기화됩니다. 현재 자동 저장 기능은 없습니다.
